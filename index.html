How to install the beta
  1. Download and extract the ZIP.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked, then the folder with manifest.json.
  4. Open a supported AI chat, click the extension, and capture.

A Chrome Web Store link will be added after review. This beta download is not a one-click store install.

Captures loaded text only. Recognized uploads get omission markers; image/file contents, diagram structure, hidden model context, and unloaded turns do not transfer. Always review the result.
